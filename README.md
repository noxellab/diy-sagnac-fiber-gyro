# 市販光通信部品を用いた簡易ファイバ・サニャック回転センサ
> A low-cost homemade fiber-optic Sagnac rotation sensor using off-the-shelf telecom components.

> **目的:** 市販部品を中心に、サニャック効果による回転信号を実際に観測する。<br>
> **基準構成:** 1550 nm / 100 m SMF / 公称直径 200 mm<br>
> **測定量:** コイル面の法線方向に投影された角速度成分<br>
> **位置づけ:** 原理確認・教育・短時間の簡易回転計測用。以下の数値は設計値であり、実測性能を保証しない。

---

## Abstract

本稿では、市販の 1550 nm 光通信部品を流用して構成する簡易ファイバ・サニャック回転センサを示す。自由空間でリング共振器を構成する代わりに、長尺のシングルモードファイバを多巻きコイルとして用いることで、比較的単純な光学系でサニャック位相を観測する。

最小の 2×2 ファイバカプラ構成では回転に伴う干渉強度変化を確認する。3×3 カプラ構成では、ポート構成と受光点を確定した場合に、複数の干渉出力から回転方向と位相を推定する。100 m、直径 200 mm、波長 1550 nm を基準設計とし、部品構成、接続、信号処理、校正、および主要な誤差要因をまとめる。

3×3版の理想式は、三つの受光値が同じ干渉信号の 120° 位相差出力である場合にだけ適用する。市販品を単純に 2×2 カプラと交換してもこの条件は成立しないため、本文では配線条件と校正方法を分けて記述する。

---

## 1. 背景

回転を光学的に検出する基本原理の一つが**サニャック効果**である。閉じた光路を互いに逆方向へ伝搬する二つの光は、光路全体が回転すると同じ時刻に出発しても伝搬時間がわずかに異なる。この差は光学位相差として観測でき、位相差は回転角速度に比例する。

リングレーザージャイロでは、この閉光路自体をレーザー共振器として構成し、逆方向に発振する光の周波数差を読む。一方、本稿の方式では外部光源をファイバカプラで二分し、同じファイバコイルを CW（時計回り）と CCW（反時計回り）に伝搬させて再結合する。これにより、レーザー共振器を自作せずに同じサニャック効果を干渉位相として扱える。

ファイバ方式を選ぶ主な理由は、**長い光路と大きな有効囲繞面積を多巻きコイルだけで確保でき、ミラーの精密アライメントが不要**だからである。さらに 1550 nm 帯では、シングルモードファイバ、カプラ、光源、InGaAs 受光器などの通信用部品を既製品として入手しやすい。

本構成は高精度な慣性センサを直接目指すものではない。まず、

1. 連続光を二つに分け、時計回り（CW）／反時計回り（CCW）に同じコイルへ通す
2. 回転による干渉変化を観測する
3. 回転方向を含む位相を取得する
4. 既知角速度で校正する

という順序で、サニャック回転計測を実際に成立させることを目的とする。

## 2. 構成方針

### 2.1 1550 nm を使う理由

1550 nm を採用する理由は、特別な研究用光学部品を前提とせず、一般的な光通信部品で一式を構成しやすいためである。

- 長尺のシングルモードファイバが入手しやすい
- 2×2 ファイバカプラが一般的
- 3×3 カプラも入手可能
- InGaAs 受光器で直接検出できる
- FC 系コネクタで着脱式に構成できる

### 2.2 2×2 と 3×3 の役割

以下では、光源の `CW`（continuous wave、連続光）と、伝搬方向の `CW`（clockwise、時計回り）を混同しないようにする。

2×2 構成は最小部品数で干渉変化を確認するために使う。位相バイアスを既知にして狭い範囲だけ読む方法はあるが、バイアスを持たない単一強度出力から、全範囲の符号付き角速度を一意に求めることはできない。

3×3 構成では、適切なポート構成から位相の異なる干渉出力を得られるため、`atan2` による位相復元が可能となり、右回転と左回転を区別できる。ただし、製品によっては標準配線で二つの干渉出力と一つのモニタ出力になるため、三つすべてを位相計算へ入力してはならない。三出力版を使う場合は、メーカーのポート定義、戻り光の取り出し方法、位相関係を確認する。

## 3. 原理

コイル面の単位法線ベクトルを \(\boldsymbol{n}\)、回転角速度ベクトルを \(\boldsymbol{\Omega}\) とし、測定対象を

\[
\Omega_n=\boldsymbol{\Omega}\cdot\boldsymbol{n}
\]

と定義する。センサが直接測るのは、回転軸全体ではなくこの法線方向成分である。

面積 \(A\) の閉光路が回転すると、逆方向に伝搬する二つの光には

\[
\Delta t=\frac{4A\Omega_n}{c^2}
\]

の伝搬時間差が生じる。波長を真空中の波長 \(\lambda\) とすると、回転によるサニャック位相差は

\[
\Delta\phi_{\mathrm{S}}=\frac{8\pi A}{\lambda c}\Omega_n
\]

となる。

多巻きファイバコイルでは各ターンの面積が加算される。半径が一定の円形コイルで、コイル内のファイバ長を \(L\)、半径を \(r\) とすると

\[
A_{\mathrm{eff}}\approx\frac{Lr}{2}
\]

なので、

\[
\boxed{
\Delta\phi_{\mathrm{S}}=
\frac{4\pi Lr}{\lambda c}\Omega_n
}
\]

となる。

多層巻きやリード部を含む実機では半径がターンごとに異なるため、実効面積は

\[
A_{\mathrm{eff}}=\sum_k\pi r_k^2
\]

で評価するか、実測した平均半径で近似する。公称直径だけでスケールファクタを確定しない。

理論スケールファクタは

\[
\boxed{
K_{\phi,\mathrm{theory}}=\frac{4\pi Lr}{\lambda c}
}
\]

であり、実測値は \(K_{\phi,\mathrm{meas}}\) として校正する。

実際の復調値には、静的な位相バイアスとドリフトが含まれる。

\[
\phi_{\mathrm{raw}}=\phi_{\mathrm{bias}}+\Delta\phi_{\mathrm{S}}+\epsilon
\]

したがって、角速度は位相バイアスを補正し、必要なら位相をアンラップした後の値から

\[
\boxed{
\Omega_n=\frac{\operatorname{unwrap}(\phi_{\mathrm{raw}}-\phi_{\mathrm{bias}})}{K_{\phi,\mathrm{meas}}}
}
\]

で求める。

### 基準設計

| パラメータ | 値 |
|---|---:|
| 波長 | 1550 nm |
| コイル内ファイバ長 | 公称 100 m |
| コイル直径 | 公称 200 mm |
| 半径 | 0.10 m（単層近似） |
| 巻数 | 約159（一定半径なら） |
| 有効面積 | 約5.0 m²（一定半径なら） |

このときの理論値は

\[
K_{\phi,\mathrm{theory}}\approx0.2704\ \mathrm{s}
\]

である。1 rpm は \(2\pi/60\) rad/s として換算する。

| 回転速度 | 理論位相差 |
|---:|---:|
| 1 rpm | 0.028 rad |
| 5 rpm | 0.142 rad |
| 10 rpm | 0.283 rad |
| 30 rpm | 0.850 rad |
| 60 rpm | 1.70 rad |

最初の動作確認は **10–30 rpm 程度**が扱いやすい。ただし、観測できるかどうかは干渉可視度、位相バイアス、TIAの飽和、ADCノイズに依存する。

## 4. 2×2 最小構成

```text
                         100 m SMF coil
                   ┌────────────────────┐
                   │                    │
                   ▼                    ▼
                Port 3              Port 4
                    \                /
                     \ 2×2 50:50    /
                      \  coupler   /
                   Port 1        Port 2
                     │              │
              source / isolator   PD → TIA → ADS1115
```

入力光は二分され、同じコイルを時計回り（CW）／反時計回り（CCW）に伝搬して再結合する。レーザー光源を使う場合は、戻り光から光源を保護し、反射の影響を減らすため 1550 nm 対応の光アイソレータを追加する。

受光強度は理想化すると

\[
I=I_0[1+V\cos(\phi_{\mathrm{bias}}+\Delta\phi_{\mathrm{S}})]
\]

で表せる。\(\phi_{\mathrm{bias}}\) が 0 または \(\pi\) 付近では、微小回転に対する一次感度

\[
\frac{\mathrm{d}I}{\mathrm{d}\Delta\phi_{\mathrm{S}}}
=-I_0V\sin(\phi_{\mathrm{bias}})
\]

が小さくなる。したがって、2×2版の 10–30 rpm 測定は干渉変化の有無を確認する定性的試験とし、速度校正や方向判別には使わない。既知の位相バイアスを追加すれば狭い範囲の符号判別は可能だが、本文の最小構成には含めない。

**2×2版の目的は「回すと干渉信号が変わる」ことの確認である。**

## 5. 3×3 構成による方向判別

### 5.1 配線条件

3×3カプラは、三つのポートを持つ二つの側を備えた双方向部品として扱う。以下の `L0`～`L2`、`R0`～`R2` は説明用の論理名であり、実際のポート番号ではない。購入したカプラのデータシートに合わせて置き換え、シリアル番号と対応表を記録する。

三つの**戻り干渉出力**を受光する構成の一例を示す。光源ポートと三つ目の受光ポートを共有するため、3ポート光サーキュレータが必要になる。

```text
                         3×3 coupler
             L0 ───────────────────── R0 ── coil end A
             L1 ───────────────────── R1 ── optical terminator
             L2 ───────────────────── R2 ── coil end B
              │             ↑
           PD0/TIA       return
              │             │
           ADS1115       circulator P2
                            ▲  │
              source ── P1 ┘  └─ P3 ── PD2/TIA

                         L1 → PD1/TIA → ADS1115
```

実際の接続は次のように確定する。

| 論理ポート | 接続 | 備考 |
|---|---|---|
| L0 | PD0 → TIA → ADS1115 | 戻り干渉出力であることを確認 |
| L1 | PD1 → TIA → ADS1115 | 戻り干渉出力であることを確認 |
| L2 | サーキュレータ P2 | 光源の送信と戻り光を分離 |
| R0 | コイル端 A | コイルの一端 |
| R1 | 光終端器 | 未使用ポートを開放しない |
| R2 | コイル端 B | コイルの他端 |
| サーキュレータ P1 | 1550 nm光源 | 連続光モード |
| サーキュレータ P3 | PD2 → TIA → ADS1115 | L2からの戻り干渉出力 |

この三出力構成は、L0、L1、L2の三つが同じ干渉信号の出力であることを、データシートまたは実測で確認できた場合だけ使用する。標準配線で二つの干渉出力と一つのモニタ出力になる製品では、モニタ出力を \(I_2\) として使わない。その場合は二出力構成として別途校正するか、サーキュレータを含む三出力構成に変更する。

光源、サーキュレータ、カプラ、コイル、受光器、TIA、ADC、MCU、バッテリは同じ回転台に固定する。光源を固定側に置く場合は、光ロータリジョイントを含む別の光学構成が必要である。

### 5.2 理想モデル

三つの受光値が同じ干渉信号の 120° 位相差出力で、オフセットとゲインを補正済みの場合に限り、正規化値 \(J_0,J_1,J_2\) を

\[
J_0=C[1+V\cos\phi]
\]

\[
J_1=C\left[1+V\cos\left(\phi+\frac{2\pi}{3}\right)\right]
\]

\[
J_2=C\left[1+V\cos\left(\phi-\frac{2\pi}{3}\right)\right]
\]

とする。

すると

\[
X=2J_0-J_1-J_2
\]

\[
Y=\sqrt{3}(J_2-J_1)
\]

から、

\[
\boxed{
\phi_{\mathrm{raw}}=
\operatorname{atan2}
\left(
\sqrt{3}(J_2-J_1),
2J_0-J_1-J_2
\right)
}
\]

で主値位相を求められる。実機では一般に

\[
\boldsymbol{v}=\boldsymbol{b}+M
\begin{bmatrix}\cos\phi\\\sin\phi\end{bmatrix}+\boldsymbol{n}
\]

とし、三チャンネルのオフセット \(\boldsymbol{b}\)、ゲイン・位相関係 \(M\)、ノイズ \(\boldsymbol{n}\) を校正する。単純な同一部品化だけでは \(M\) を理想行列にできない。

校正後は、最小二乗で

\[
\boldsymbol{q}=M^{+}(\boldsymbol{v}-\boldsymbol{b}),\qquad
\phi_{\mathrm{raw}}=\operatorname{atan2}(q_y,q_x)
\]

とする。ここで \(M^{+}\) は校正行列の擬似逆行列である。上の理想式は、実測した \(M\) が理想形に十分近いかを確認するための簡易式として使う。

角速度へ変換する前に、静的位相バイアスを補正し、主値の折り返しをアンラップする。

\[
\Delta\phi_{\mathrm{S}}=\operatorname{unwrap}(\phi_{\mathrm{raw}}-\phi_{\mathrm{bias}})
\]

\[
\boxed{
\Omega_n=\frac{\Delta\phi_{\mathrm{S}}}{K_{\phi,\mathrm{meas}}}
}
\]

`atan2()` の一回の出力は \(-\pi\)～\(+\pi\) の主値である。基準設計で ±111 rpm と書けるのは、バイアスを中心に主値を使う場合の公称範囲である。アンラップしない値は約 222 rpm 周期で同じ位相になるため、連続測定の範囲はサンプリング間隔、回転変化量、アンラップ処理で決まる。

\(I_1\) と \(I_2\) の順序は正回転の定義を変える。コイル面をどちら側から見た回転を正とするかを決め、既知の正回転で符号を確認する。

## 9. コイル製作

100 m のファイバをボビンへ巻く。φ200 mm は単層・一定半径の理論値であり、実機ではケーブル外径とボビン幅から巻き方を先に決める。

製作前に次を記録する。

- ボビンの内径、外径、軸方向の巻き幅
- ケーブル外径、最小曲げ半径、実際の光ファイバ長
- 層数、各層の巻き数、各層の平均半径
- コイル面の法線方向と、正回転を定義する視方向

多層巻きの有効面積は、各ターンの半径を使って

\[
A_{\mathrm{eff}}=\sum_k\pi r_k^2
\]

で見積もる。100 mをφ200 mmへ巻けるかは、ケーブル外径と巻き幅から確認する。巻き終わった後の内径・外径・層数を記録し、理論値と実測校正値を区別する。

注意点：

- ファイバを強く引っ張らない
- 急な曲げを作らない
- 一点だけを強く固定しない
- 巻き張力をなるべく一定にする
- 実際のケーブルの最小曲げ半径を下回らない
- 巻き終わりとコネクタのリード部をコイル面へ無理に押し付けない

光学系を回転台へ載せる場合は、光源、必要な光アイソレータ／サーキュレータ、カプラ、コイル、受光器までを同じ剛体へ固定する。ADC、MCU、バッテリも同じ台へ載せれば、回転部分と固定部分を光ファイバで接続せずに済む。固定側に光源を残す場合は、光ロータリジョイントを含む別構成にする。

## 10. 信号処理

### 10.1 2×2 版

ADS1115を使う構成では、Nano Everyの `analogRead()` ではなく、ADS1115の single-ended channel 0 を読む。以下はドライバAPIに依存しない擬似コードである。

Nano Everyの `analogRead()` は内蔵ADCを読むため、ADS1115の値を返さない。ADS1115をBOMに残す限り、全チャンネルをI²C経由で読む。

```cpp
// 擬似コード。read_ads1115_single_ended() は使用するADS1115ドライバに置き換える。
int16_t pd = read_ads1115_single_ended(0);
Serial.println(pd);
```

静止状態と 10–30 rpm 程度の回転状態で光量が変化するか確認する。2×2版では、ここで記録するのは受光強度であり、符号付き角速度ではない。

---

### 10.2 3×3 版

三つの戻り干渉出力を、同じADC設定で一つのフレームとして取得する。ADS1115は逐次変換なので、各値に同じフレーム番号と取得時刻を付ける。

```cpp
// 擬似コード。チャンネル番号は購入したポート対応表に合わせる。
float v0 = read_ads1115_single_ended(0);
float v1 = read_ads1115_single_ended(1);
float v2 = read_ads1115_single_ended(2);

// b_i と g_i は校正したオフセットとゲイン。
float i0 = (v0 - b0) / g0;
float i1 = (v1 - b1) / g1;
float i2 = (v2 - b2) / g2;

float x = 2.0f * i0 - i1 - i2;
float y = 1.7320508f * (i2 - i1);

float phi_raw = atan2(y, x);
float delta_phi_s = unwrap(phi_raw - phi_bias);
```

上の `x`、`y` は、三チャンネルの位相差が120°で、オフセット・ゲイン補正後の理想モデルに対する簡易式である。位相差や振幅が理想値からずれる場合は、5.2節の校正行列 \(M\) を使う。

100 m、直径 200 mm、1550 nm の理論スケールファクタは初期値として使い、最終計算には校正値を使う。

```cpp
// 擬似コード。校正後は保存したKphi_measuredを読み込む。
const float Kphi_theory = 0.2704f;  // s。実測値ではない
float Kphi_measured = Kphi_theory;   // 初期確認用。校正後に置き換える。

float omega_n = delta_phi_s / Kphi_measured;  // rad/s
float rpm     = omega_n * 60.0f / (2.0f * PI);
```

`phi_bias` はゼロ回転時の位相バイアス、`unwrap()` は時間方向の位相アンラップである。実装ではアンラップ前の位相差が一サンプル間に \(\pi\) を超えないようにサンプリング周期を決める。

`atan2()` は \(-\pi\) ～ \(+\pi\) で折り返すため、この基準設計では単純な測定範囲はおよそ

\[
-111\ \mathrm{rpm}
<
\mathrm{rpm}
<
+111\ \mathrm{rpm}
\]

となる。ただしこれはバイアスを中心に主値を使う場合の公称範囲であり、ハードウェアの安全な最大回転速度を意味しない。アンラップしない位相は約222 rpm周期で同じ値になる。

## 11. 校正と動作確認

### 11.1 暗電流・飽和の確認

1. 光源をOFFにして各受光チャンネルの暗オフセットを記録する。
2. 光源をONにし、各TIA出力がADC入力範囲内にあることを確認する。
3. 光源の設定、受光電力、TIAの \(R_f\)、ADCのPGA、サンプリングレートを記録する。
4. 飽和、クリップ、未接続ポートからの不規則な変動がないことを確認する。

### 11.2 ゼロ点

3×3版では、生の三チャンネル値の平均を位相オフセットとして差し引かない。まずオフセット・ゲイン・位相関係を補正して \(\phi_{\mathrm{raw}}\) を求め、短時間の静止データから円平均

\[
\phi_{\mathrm{bias}}=\operatorname{atan2}\left(\operatorname{mean}(\sin\phi_{\mathrm{raw}}),
\operatorname{mean}(\cos\phi_{\mathrm{raw}})\right)
\]

を求める。静止時の標準偏差またはRMSも記録する。ここでのゼロは、設置姿勢、地球自転、機械台の残留回転を含む装置上の相対ゼロである。

### 11.3 3×3チャンネル校正

既知角速度を測れる回転台またはタコメータを使い、十分な位相変化を与える。各サンプルの三チャンネル値を

\[
\boldsymbol{v}=\boldsymbol{b}+M
\begin{bmatrix}\cos\phi\\\sin\phi\end{bmatrix}
\]

へフィットし、オフセット \(\boldsymbol{b}\) と校正行列 \(M\) を求める。理想120°式を使う場合でも、三チャンネルのゲイン差とDCオフセットを先に補正する。校正に必要な位相範囲を手動回転だけで確保できない場合は、三出力式を無理に適用せず、メーカーの個体データまたは別の位相掃引方法を使う。

### 11.4 スケールと符号

基準器で実際の角速度 \(\Omega_n\) を測り、次の速度を各方向で複数回取得する。

```text
-30
-20
-10
0
+10
+20
+30 rpm
```

手動で「約」と測った値は動作確認用であり、スケール校正値には使わない。rpmを

\[
\Omega_n=\mathrm{rpm}\times\frac{2\pi}{60}
\]

で rad/s に変換し、生の位相をアンラップした後、

\[
\phi_{\mathrm{cont}}=K_{\phi,\mathrm{meas}}\Omega_n+b
\]

として線形回帰する。\(b\) は装置固有の位相バイアスであり、\(\Delta\phi_{\mathrm{S}}=\phi_{\mathrm{cont}}-b\) として角速度へ変換する。\(K_{\phi,\mathrm{meas}}\) の単位は s である。正回転の向きは右手則で定義し、既知の正回転で \(I_1/I_2\) の順序と符号を確認する。

### 11.5 最初の確認手順

1. 光源、必要なアイソレータ／サーキュレータ、カプラ、コイル、受光器を接続する。
2. 静止状態で暗オフセット、受光値、TIA出力、ADC値を記録する。
3. 基準器で約 +10 rpm を確認し、数秒間測定する。
4. 静止させ、ゼロ点の再現性を確認する。
5. 基準器で約 -10 rpm を確認し、位相の符号が反転することを確認する。
6. 10–30 rpmの複数速度で比例関係と残差を確認する。
7. 別の時刻または温度条件で同じ測定を繰り返し、ゼロ点ドリフトを記録する。

## 12. 主な誤差と簡易対策

理想式では時計回り／反時計回り光に共通する光路変化は相殺されるが、実機では温度分布、偏光、反射、部品不均衡、機械応力などが完全には相反にならず、回転と無関係な位相変化として現れる。簡易機ではこれらを完全に除去するより、**短時間測定・機械固定・チャンネル校正・ゼロ点校正**によって影響を抑える方針とする。

| 要因 | 症状 | 対策 |
|---|---|---|
| 温度変化 | ゼロ点ドリフト | コイルを断熱し、温度安定後に測定 |
| 偏光変動 | 干渉振幅の変化 | ファイバへの曲げ・圧力を減らし、変動を記録 |
| コネクタ反射・戻り光 | 不規則な干渉変動、光源への反射 | 端面清掃、未使用ポート終端、アイソレータを使用 |
| 3×3カプラ不均衡 | 位相計算の歪み | 個体の分岐比・位相を測定し、校正行列で補正 |
| 受光器・TIAゲイン差 | オフセット・楕円歪み | 暗オフセット、ゲイン、位相関係をチャンネルごとに校正 |
| 光源の出力変動・コヒーレント雑音 | 共通モード変動、干渉コントラスト低下 | 連続光・変調設定を固定し、必要なら光源を変更して比較 |
| TIA・ADCの飽和 | 波形クリップ、位相飛び | 光パワー、\(R_f\)、\(C_f\)、PGA、電源電圧を見直す |
| ADCの逐次変換・折り返し | チャンネル間の時間ずれ、エイリアシング | フレーム時刻を記録し、アナログ帯域を制限 |
| コイル形状・層数 | スケールファクタのずれ | 実効面積を見積もり、既知角速度で校正 |
| 軸の傾き | 角速度の投影誤差 | コイル面の法線と正回転方向を記録 |
| 機械振動・偏心 | 回転以外の信号 | コイルを剛性のある回転台へ固定し、保護カバーを付ける |

この簡易構成では、まず短時間の手動回転測定を対象とする。

## 13. 安全上の注意

1550 nm 光は肉眼では見えない。

- 通電中のファイバ端面を覗かない
- 運転中の未使用ポートには光終端器を付け、停止中は防塵キャップを付ける
- 光源 ON のまま端面を清掃しない
- 製品のレーザークラスを確認する
- 必要以上に高出力の光源を使用しない
- 光源の戻り光許容値を確認し、必要なら光アイソレータを入れる
- TIA、ADC、光源の電源電圧と電流制限を確認する
- 回転台の偏心、固定具、保護カバー、バッテリ固定を確認する
- 光ファイバを切断した場合は、ガラス片を粘着テープ等で回収し、素手で触らない

## 14. まとめ

この構成の核心は、**長尺ファイバを多巻きして有効面積を稼ぎ、同一コイルを逆方向に進む光の位相差を測ること**にある。

- 2×2 版：最小構成でサニャック干渉の変化を確認する
- 3×3 版：ポート構成を確認した三つの戻り干渉出力から、校正後に符号付き位相を復元する
- 100 m / φ200 mm / 1550 nm：理論値 \(K_{\phi,\mathrm{theory}}\approx0.2704\,\mathrm{s}\)
- 実機では暗オフセット、チャンネル行列、位相バイアス、スケールファクタを基準回転で校正する

精度を決める主因は理論式そのものより、温度、偏光、反射、機械応力、コイル形状、受光系の不均衡である。そのため、まず基準器で確認した 10–30 rpm 程度の回転を使って光学系と復調処理が正しく動作することを確認する。
