# 市販光通信部品を用いた3×3サニャック干渉型光ファイバジャイロPoC

[English](README.en.md) | 日本語

> **目的:** 市販部品を中心に、3×3構成でサニャック位相と回転方向を実際に観測する。<br>
> **基準構成:** 1550 nm / 100 m SMF / 公称直径 200 mm / 3×3カプラ / 3ポートサーキュレータ / 3受光チャンネル<br>
> **測定量:** コイル面の法線方向に投影された角速度成分<br>
> **PoC完了条件:** 三つの戻り干渉出力を取得し、校正後に正負の既知角速度を符号付きで復元する<br>
> **位置づけ:** 原理確認・教育・短時間の簡易回転計測用。以下の数値は設計値であり、実測性能を保証しない。

---

## Abstract

本稿では、市販の 1550 nm 光通信部品を流用して構成する簡易ファイバ・サニャック回転センサを示す。自由空間でリング共振器を構成する代わりに、長尺のシングルモードファイバを多巻きコイルとして用いることで、比較的単純な光学系でサニャック位相を観測する。

3×3カプラ、3ポートサーキュレータ、100 mコイル、三つの受光チャンネルを組み合わせ、同じコイルを逆方向に伝搬した光の戻り干渉出力から回転方向と位相を推定する。100 m、直径 200 mm、波長 1550 nm を基準設計とし、部品構成、接続、信号処理、校正、および主要な誤差要因をまとめる。

理想式は、三つの受光値が同じ干渉信号の 120° 位相差出力である場合にだけ適用する。購入品のポート定義と戻り光の取り出し方法を確認し、三つすべてを干渉出力として取得できない部品はこのPoCには採用しない。

---

## 1. 背景

回転を光学的に検出する基本原理の一つが**サニャック効果**である。閉じた光路を互いに逆方向へ伝搬する二つの光は、光路全体が回転すると同じ時刻に出発しても伝搬時間がわずかに異なる。この差は光学位相差として観測でき、位相差は回転角速度に比例する。

リングレーザージャイロでは、この閉光路自体をレーザー共振器として構成し、逆方向に発振する光の周波数差を読む。一方、本稿の方式では外部光源を3×3カプラへ入力し、二つのポートを同じファイバコイルの両端へ接続して、CW（時計回り）とCCW（反時計回り）に伝搬させて再結合する。残るポートは光終端し、三つの戻りポートから干渉出力を取り出す。これにより、レーザー共振器を自作せずに同じサニャック効果を干渉位相として扱える。

ファイバ方式を選ぶ主な理由は、**長い光路と大きな有効囲繞面積を多巻きコイルだけで確保でき、ミラーの精密アライメントが不要**だからである。さらに 1550 nm 帯では、シングルモードファイバ、カプラ、光源、InGaAs 受光器などの通信用部品を既製品として入手しやすい。

本構成は高精度な慣性センサを直接目指すものではない。まず、

1. 3×3カプラとコイルで時計回り（CW）／反時計回り（CCW）の二つの光路を構成する
2. 三つの戻り干渉出力を同じADCフレームで取得する
3. 校正した三チャンネルから回転方向を含む位相を復元する
4. 既知角速度でスケール、符号、再現性を校正する

という順序で、サニャック回転計測を実際に成立させることを目的とする。

## 2. 構成方針

### 2.1 1550 nm を使う理由

1550 nm を採用する理由は、特別な研究用光学部品を前提とせず、一般的な光通信部品で一式を構成しやすいためである。

- 長尺のシングルモードファイバが入手しやすい
- 3×3 カプラとポート仕様を選べる
- 3ポート光サーキュレータで送信光と戻り光を分離できる
- InGaAs 受光器で直接検出できる
- FC 系コネクタで着脱式に構成できる

### 2.2 完成系PoCの役割分担

以下では、光源の `CW`（continuous wave、連続光）と、伝搬方向の `CW`（clockwise、時計回り）を混同しないようにする。

3×3構成では、適切なポート配線から位相の異なる三つの戻り干渉出力を得る。三チャンネルを `atan2` に入力することで位相を復元し、右回転と左回転を区別する。

完成系PoCでは、3×3カプラの一つのポートから光を送り、二つのポートをコイル両端へ接続し、残るポートを光終端する。戻り光は三つの反対側ポートから取り出し、光源と共有するポートは3ポートサーキュレータで受光器へ分離する。三つの戻りポートが同じ干渉信号の出力であることを、メーカーのポート資料または実測で確認できる部品だけを使う。

## 3. 原理

コイル面の単位法線ベクトルを $\boldsymbol{n}$、回転角速度ベクトルを $\boldsymbol{\Omega}$ とし、測定対象を

$$
\Omega_n=\boldsymbol{\Omega}\cdot\boldsymbol{n}
$$

と定義する。センサが直接測るのは、回転軸全体ではなくこの法線方向成分である。

面積 $A$ の閉光路が回転すると、逆方向に伝搬する二つの光には

$$
\Delta t=\frac{4A\Omega_n}{c^2}
$$

の伝搬時間差が生じる。波長を真空中の波長 $\lambda$ とすると、回転によるサニャック位相差は

$$
\Delta\phi_{\mathrm{S}}=\frac{8\pi A}{\lambda c}\Omega_n
$$

となる。

多巻きファイバコイルでは各ターンの面積が加算される。半径が一定の円形コイルで、コイル内のファイバ長を $L$、半径を $r$ とすると

$$
A_{\mathrm{eff}}\approx\frac{Lr}{2}
$$

なので、

$$
\boxed{
\Delta\phi_{\mathrm{S}}=
\frac{4\pi Lr}{\lambda c}\Omega_n
}
$$

となる。

多層巻きやリード部を含む実機では半径がターンごとに異なるため、実効面積は

$$
A_{\mathrm{eff}}=\sum_k\pi r_k^2
$$

で評価するか、実測した平均半径で近似する。公称直径だけでスケールファクタを確定しない。

理論スケールファクタは

$$
\boxed{
K_{\phi,\mathrm{theory}}=\frac{4\pi Lr}{\lambda c}
}
$$

であり、実測値は $K_{\phi,\mathrm{meas}}$ として校正する。

実際の復調値には、静的な位相バイアスとドリフトが含まれる。

$$
\phi_{\mathrm{raw}}=\phi_{\mathrm{bias}}+\Delta\phi_{\mathrm{S}}+\epsilon
$$

したがって、角速度は位相バイアスを補正し、必要なら位相をアンラップした後の値から

$$
\boxed{
\Omega_n=\frac{\mathrm{unwrap}(\phi_{\mathrm{raw}}-\phi_{\mathrm{bias}})}{K_{\phi,\mathrm{meas}}}
}
$$

で求める。

### 基準設計

| パラメータ | 値 |
|---|---:|
| 波長 | 1550 nm |
| コイル内ファイバ長 | 公称 100 m |
| コイル直径 | 公称 200 mm |
| 半径 | 0.10 m（単層近似） |
| 巻数 | 約159（一定半径なら） |
| 有効面積 | 約5.0 m²（一定半径なら） |

このときの理論値は

$$
K_{\phi,\mathrm{theory}}\approx0.2704\ \mathrm{s}
$$

である。1 rpm は $2\pi/60$ rad/s として換算する。

| 回転速度 | 理論位相差 |
|---:|---:|
| 1 rpm | 0.028 rad |
| 5 rpm | 0.142 rad |
| 10 rpm | 0.283 rad |
| 30 rpm | 0.850 rad |
| 60 rpm | 1.70 rad |

最初の動作確認は **10–30 rpm 程度**が扱いやすい。ただし、観測できるかどうかは干渉可視度、位相バイアス、TIAの飽和、ADCノイズに依存する。

## 4. 3×3 完成系PoCの仕様

本稿で製作するのは、三つの戻り干渉出力から位相と回転方向を復元する3×3構成だけである。光学系・受光・ADC・MCUを同じ回転台へ固定し、固定側とは電気スリップリング（電源・UART）だけで接続する。

必須ブロックは次のとおりである。

- 1550 nmの連続光源 → 3ポートサーキュレータ → 3×3シングルモードカプラの一つのポート
- 二つのカプラポート、ループ内の手動偏波コントローラ、100 m SMFコイルによるCW／CCW光路
- 未使用ポートの光終端
- 三つの戻り干渉出力 → InGaAs受光器 → TIA → ADS1115
- MCUによる三チャンネル補正、位相復元、アンラップ、角速度換算
- 電気スリップリング経由の給電とUART、PCでのフレームと基準速度の記録
- −120～+120 rpmを定速保持できる回転台と速度基準

PoCの受入条件は、次のすべてを満たすこととする。

1. 購入品のポート資料と11.2節の実測判定により、三つの戻りポートが独立な位相情報を持つ干渉出力であることを確認する。
2. 暗オフセット補正後、三チャンネルを飽和させずに同一フレームとして取得できる。
3. 既知の正回転・負回転で位相の符号が反転し、校正後の角速度が基準器と同じ傾向を示す。
4. 複数速度で求めたスケールファクタ、残差、ゼロ点再現性を記録できる。

## 5. 3×3 完成系の配線と方向判別

### 5.1 配線条件

3×3カプラは、三つのポートを持つ二つの側を備えた双方向部品として扱う。以下の `L0`～`L2`、`R0`～`R2` は説明用の論理名であり、実際のポート番号ではない。購入したカプラのデータシートに合わせて置き換え、シリアル番号と対応表を記録する。

三つの**戻り干渉出力**を受光する構成を示す。光源ポートと三つ目の受光ポートを共有するため、3ポート光サーキュレータが必要になる。

```text
                ┌────────────┐
  source ───────┤P1          │
                │ circulator │     ┌─────────────────────┐
  PD2 ──────────┤P3        P2├─────┤L2                 R2├── coil end B
                └────────────┘     │                     │
  PD1 ─────────────────────────────┤L1   3×3 coupler   R1├── terminator
                                   │                     │
  PD0 ─────────────────────────────┤L0                 R0├── polarization controller ── coil end A
                                   └─────────────────────┘
```

各PDの後段はTIAを経てADS1115へ入る。実際の接続は次のように確定する。

| 論理ポート | 接続 | 備考 |
|---|---|---|
| L0 | PD0 → TIA → ADS1115 | 戻り干渉出力 |
| L1 | PD1 → TIA → ADS1115 | 戻り干渉出力 |
| L2 | サーキュレータ P2 | 送信と戻りを共有する相反ポート |
| R0 | 偏波コントローラ → コイル端 A | ループ内で干渉可視度を調整 |
| R1 | 光終端器 | 未使用ポートを開放しない |
| R2 | コイル端 B | コイルの他端 |
| サーキュレータ P1 | 1550 nm光源 | 連続光モード |
| サーキュレータ P3 | PD2 → TIA → ADS1115 | L2からの戻り干渉出力 |

このPoCでは、L0、L1、L2の三つすべてを同じ干渉信号の出力として位相計算に使う。三つの戻り出力が干渉信号であることをデータシートまたは実測で確認できない製品、モニタ出力を含む製品は採用しない。

光源、サーキュレータ、カプラ、偏波コントローラ、コイル、受光器、TIA、ADC、MCUは同じ回転台に固定する。固定側とは電気スリップリング（電源・UART）だけで接続し、回転部と固定部の間に光ファイバを通さない。

### 5.2 理想モデル

三つの受光値が同じ干渉信号の 120° 位相差出力で、オフセットとゲインを補正済みの場合に限り、正規化値 $J_0,J_1,J_2$ を

$$
J_0=C[1+V\cos\phi]
$$

$$
J_1=C\left[1+V\cos\left(\phi+\frac{2\pi}{3}\right)\right]
$$

$$
J_2=C\left[1+V\cos\left(\phi-\frac{2\pi}{3}\right)\right]
$$

とする。

この配線では、L2から出てL2へ戻るCW経路とCCW経路が互いに同じ経路の逆向きになる。偏光の影響を除けば、相反性により二つの光の結合係数が等しく、L2の出力は位相バイアス0の $\cos\Delta\phi_{\mathrm{S}}$ となり、静止時に干渉最大となる。理想対称カプラでは、L0とL1の出力はこれに対して±120°ずれる。そこで $J_0$ にPD2を、$J_1$、$J_2$ にPD0、PD1を割り当てる。$J_1$ と $J_2$ の割当は、既知の正回転で $\phi$ が増える順に決める。

すると

$$
X=2J_0-J_1-J_2
$$

$$
Y=\sqrt{3}(J_2-J_1)
$$

から、

$$
\boxed{
\phi_{\mathrm{raw}}=
\mathrm{atan2}
\left(
\sqrt{3}(J_2-J_1),
2J_0-J_1-J_2
\right)
}
$$

で主値位相を求められる。実機では一般に

$$
\boldsymbol{v}=\boldsymbol{b}+M
\begin{bmatrix}\cos\phi\\\sin\phi\end{bmatrix}+\boldsymbol{\epsilon}
$$

とし、三チャンネルのオフセット $\boldsymbol{b}$、ゲイン・位相関係 $M$、ノイズ $\boldsymbol{\epsilon}$ を校正する。単純な同一部品化だけでは $M$ を理想行列にできない。

校正後は、最小二乗で

$$
\boldsymbol{q}=M^{+}(\boldsymbol{v}-\boldsymbol{b}),\qquad
\phi_{\mathrm{raw}}=\mathrm{atan2}(q_y,q_x)
$$

とする。ここで $M^{+}$ は校正行列の擬似逆行列である。上の理想式は、実測した $M$ が理想形に十分近いかを確認するための簡易式として使う。

その後、3章の式で位相バイアスを補正し、主値の折り返しをアンラップして角速度へ換算する。$\Omega_n$ の正の向きは3章の法線 $\boldsymbol{n}$ に対する右手則で決まるため、$\boldsymbol{n}$ がコイルのどちらの面を向くかを記録する。

## 7. 部品ごとの注意点

### 光源 — Joinwit JW3109

候補部品であり、注文時に構成を指定する。1550 nm の LD、連続光モード、変調なしを選ぶ。JW3109はFP-LD、LEDなどのエミッタを選択でき、1550 nmでは変調モードも用意されているため、「1550 nm」とだけ指定してはならない。メーカー仕様では、LDの出力は −7 dBm、コネクタは FC/PC、電源は単3電池3本である。10分自動OFF機能は無効にして使う。スペクトル幅と戻り光許容値も確認する。

---

### 3×3 カプラ — AC Photonics

1550 nm、Single Mode、3×3 の fused coupler を指定する。完成系PoCのポート配置は、本文5章の論理ポートを購入品のデータシートへ対応付けてから配線する。

注文時の目安：

```text
Configuration : 3x3
Wavelength    : 1550 nm
Split         : approximately 33:33:33
Fiber         : single mode
Connector     : FC/PC
Port report   : insertion loss、uniformity、PDL、directivity、ポート位相または測定方法を確認
```

3×3カプラは製品ごとに分岐比、PDL、ポート位相特性が異なる。標準仕様に120°位相関係が明記されていない場合は、メーカーの個体データまたは実測で確認する。戻り側の三ポートすべてから同じ干渉信号を取り出せる構成であることを確認し、確認できない製品は採用しない。

---

### 3ポート光サーキュレータ — Thorlabs 6015-3-FC

SMファイバ、FC/PC、1525–1610 nm対応で1550 nmを含む。[メーカーのV21仕様資料](https://www.thorlabs.com/catalogpages/V21/1119.pdf)にP1→P2、P2→P3の伝送経路が示されている。メーカー仕様では挿入損失は 0.8 dB（typ.）、アイソレーションは 40 dB 超である。カプラからの戻り光はP3へ送られ光源側のP1へはほとんど戻らないため、別の光アイソレータは使わない。注文時に現行仕様と供給可否を確認し、FC/APC版と取り違えない。

光源→P1、P2→カプラL2、P3→PD2へ接続する。納入品のラベルと資料でポート番号を照合し、カプラ接続前に低出力光とパワーメータでP1→P2、P2→P3の透過を確認する。

---

### 偏波コントローラ — Thorlabs FPC031

3パドル（Ø27 mm）の手動偏波コントローラで、1260–1625 nm対応、FC/PCコネクタ付きのファイバを内蔵する。カプラR0とコイル端Aの間に入れる。偏光補償のないSMFループでは、CW光とCCW光の偏光状態がループの複屈折によって一致しなくなり、干渉可視度が下がる。最悪の場合は干渉がほぼ消えるため、11.1節の手順で可視度を最大化してから固定する。

```text
Fiber grade   : G.657.A1 / A2
Length        : 100 m
Cable diameter: 仕様値を確認
Minimum bend  : 仕様値を確認
```

直径 200 mm 程度へ巻く場合は、曲げに強い G.657 系が扱いやすい。ただし、ケーブル外径、最小曲げ半径、巻き幅、層数を確認し、100 mがボビンへ収まるかを先に計算する。

### 光終端器 — Thorlabs FTFC1

FC/PC用の光終端器で、戻り損失は50 dB以上である。R1のコネクタ形状に合わせて、直接または嵌合スリーブで取り付ける。

### InGaAs 受光素子 — Thorlabs FGA01FC

1550 nm 対応のファイバ結合 InGaAs PIN フォトダイオード。

アンプは内蔵されていないため、後段に TIA が必要。受光電流は光パワーと波長依存の受光感度から見積もり、TIAの飽和電圧を超えないようにする。ESDにも注意する。

### TIA — Texas Instruments OPA381

フォトダイオードの電流を電圧へ変換する。OPA381の電源電圧、フォトダイオードの逆バイアス、出力ヘッドルーム、入力容量を含めて回路を設計する。

初期検討値の範囲であり、無条件に使用してはならない。

```text
Rf : 10 kΩ ～ 100 kΩ
Cf : 数 pF ～ 数十 pF
```

全周校正では三チャンネルとも干渉最大（カプラ入射光の約4/9）に達する。JW3109の −7 dBm、サーキュレータ挿入損失 0.8 dB、理想カプラを仮定すると、受光電力の上限は約 0.07 mW となる。静止時に最大となるのは相反ポートのPD2である。

この最大受光について

$$
V_{\mathrm{TIA}}\approx I_{\mathrm{PD}}R_f,
\qquad I_{\mathrm{PD}}\approx P_{\mathrm{PD}}\mathcal{R}(\lambda)
$$

で出力を見積もる。受光回路が飽和する場合は $R_f$ を下げ、信号が小さい場合は上げる。$C_f$ はフォトダイオード容量、入力寄生容量、OPA381のGBW、必要帯域から安定性を確認して決める。

### ADC — ADS1115

4 ch / 16 bit、8–860 SPS、I²C接続のADC。入力はマルチプレクサ式なので、三チャンネルは同時サンプリングではない。

3受光チャンネルを1個で取得できる。使用するPGA範囲、電源電圧、チャンネル走査周期、アナログ帯域を記録する。逐次変換によるチャンネル間の時間差は、フレーム番号と取得時刻で管理する。

6回路、定格2 A、最大300 rpm。回転軸と同軸に取り付け、電源2回路とUART 2回路に使う。スリップリング経由の電源は回転台上のレギュレータで安定化してから使う。固定側のUARTはUSB–UART変換器でPCへ接続する。

## 9. コイル製作

100 m のファイバをボビンへ巻く。φ200 mm は単層・一定半径の理論値であり、実機ではケーブル外径とボビン幅から巻き方を先に決める。

製作前に次を記録する。

- ボビンの内径、外径、軸方向の巻き幅
- ケーブル外径、最小曲げ半径、実際の光ファイバ長
- 層数、各層の巻き数、各層の平均半径
- コイル面の法線方向と、正回転を定義する視方向

多層巻きの有効面積は3章の $A_{\mathrm{eff}}=\sum_k\pi r_k^2$ で見積もる。巻き終わった後の内径・外径・層数を記録し、理論値と実測校正値を区別する。

注意点：

- ファイバを強く引っ張らない
- 急な曲げを作らない
- 一点だけを強く固定しない
- 巻き張力をなるべく一定にする
- 実際のケーブルの最小曲げ半径を下回らない
- 巻き終わりとコネクタのリード部をコイル面へ無理に押し付けない

## 10. 信号処理

### 10.1 三チャンネルフレーム取得

三つの戻り干渉出力を同じADC設定で一つのフレームとして取得する。ADS1115は逐次変換なので、各値に同じフレーム番号と取得時刻を付け、チャンネル間の時間差を記録する。Nano Everyの `analogRead()` は使わず、全チャンネルをADS1115から読む。

フレームはスリップリング経由のUARTでPCへ送り、PCは基準器の速度を受信時刻とともに記録する。11章の校正は定常区間だけを使うため、この時刻対応で足りる。UARTの通信速度は、フレームレートと1フレームのバイト数から決める。

```cpp
// 擬似コード。チャンネル番号は購入したポート対応表に合わせる。
uint32_t frame = next_frame_number();
uint32_t t0 = timestamp_us();
float v0 = read_ads1115_single_ended(0);
uint32_t t1 = timestamp_us();
float v1 = read_ads1115_single_ended(1);
uint32_t t2 = timestamp_us();
float v2 = read_ads1115_single_ended(2);
send_frame_uart(frame, t0, t1, t2, v0, v1, v2);
```

---

### 10.2 三チャンネル位相復元と角速度換算

10.1で取得した三チャンネル値に、11.2節で求めたオフセットと校正行列の擬似逆行列を適用する。以下は処理順を示す擬似コードであり、実行可能なファームウェアではない。校正未完了、クリップ、読出し失敗、干渉振幅不足のフレームは角速度計算から除外する。

```cpp
// b[3]とP[2][3]は校正値。PはMの擬似逆行列で、ゲイン補正も含む。
float d0 = v0 - b[0];
float d1 = v1 - b[1];
float d2 = v2 - b[2];
float x = P[0][0] * d0 + P[0][1] * d1 + P[0][2] * d2;
float y = P[1][0] * d0 + P[1][1] * d1 + P[1][2] * d2;

float phi_raw = atan2(y, x);
float delta_phi_s = unwrap(phi_raw - phi_bias);
```

`x`、`y` は5.2節の補正後ベクトルの二成分である。理想120°式は初期診断に用い、行列補正と別のゲイン補正を二重に適用しない。

100 m、直径 200 mm、1550 nm の理論スケールファクタ $K_{\phi,\mathrm{theory}}\approx0.2704$ s は照合用であり、最終計算には11.4節の校正値を使う。

```cpp
// 擬似コード。Kphi_measuredは11.4節で保存した校正値。
float Kphi_measured = load_calibrated_scale_factor();  // s

float omega_n = delta_phi_s / Kphi_measured;  // rad/s
float rpm     = omega_n * 60.0f / (2.0f * PI);
```

`phi_bias` は11.3節で求めた位相バイアス、`unwrap()` は時間方向の位相アンラップである。実装ではアンラップ前の位相差が一サンプル間に $\pi$ を超えないようにサンプリング周期を決める。

`atan2()` は $-\pi$ ～ $+\pi$ で折り返すため、この基準設計では単純な測定範囲はおよそ

$$
-111\ \mathrm{rpm}
<
\mathrm{rpm}
<
+111\ \mathrm{rpm}
$$

となる。ただしこれはバイアスを中心に主値を使う場合の公称範囲であり、ハードウェアの安全な最大回転速度を意味しない。アンラップしない位相は約222 rpm周期で同じ値になる。

## 11. 校正と動作確認

11.1節から順に実施する。校正はPCに記録した生フレームで行い、校正係数、ポート対応、ADC設定を一組として保存してMCUへ書き込む。

### 11.1 受光・偏光・飽和の確認

1. 光源をOFFにして各受光チャンネルの暗オフセットを記録する。
2. 光源をONにし、静止状態でPD2の受光が最大、PD0とPD1が小さくなるよう偏波コントローラを調整し、以後固定する。
3. 各TIA出力がADC入力範囲内にあることを確認する。$R_f$ は7章の最大受光で決め、11.2節の掃引中も全チャンネルでクリップがないことを確認する。
4. 光源の設定、受光電力、TIAの $R_f$、ADCのPGA、サンプリングレートを記録する。
5. 未接続ポートからの不規則な変動がないことを確認する。

### 11.2 3×3チャンネル校正

6.2節の回転台と基準器を使い、三チャンネルすべてに位相一周期以上の変化を与える。各サンプルの三チャンネル値を

$$
\boldsymbol{v}=\boldsymbol{b}+M
\begin{bmatrix}\cos\phi\\\sin\phi\end{bmatrix}
$$

へフィットし、オフセット $\boldsymbol{b}$ と3行2列の校正行列 $M$ を求める。位相が未知の場合は三次元の受光値が描く楕円を当てはめ、単位円へ写像する。残る位相原点と向きの自由度は、PD2（$J_0$）の干渉最大を $\phi=0$ とし、既知の正回転で $\phi$ が増える向きを正として確定する。暗オフセットだけを $\boldsymbol{b}$ として使わず、光源ON時のDC成分も含める。

実測判定は次の手順で行う。

1. 光源設定・偏波コントローラ・TIAゲイン・ADC設定を固定する。静止時に各チャンネルの短時間ノイズ標準偏差 $\sigma_i$ を取得し、測定時間と実効帯域を記録する。
2. 回転台を約18 rpm刻みで −120 rpm から +120 rpm まで変え、各速度で定速を保持して三つの生値と基準器の速度を記録する。サニャック位相は回転角ではなく角速度で決まるため、一定速度で長く回しても位相は掃引されない。三チャンネルの変化が単なる光源強度の共通変動でないことを、独立な二つの位相成分から確認する。
3. 楕円全周を覆うデータで $\boldsymbol{b}$ と $M$ を推定する。少なくとも位相12区間に各10フレームを取得し、別の掃引を検証用に残す。速度変更中の過渡区間は除外し、定常区間を用いる。
4. 各行の変調振幅 $A_i=\sqrt{M_{i0}^2+M_{i1}^2}$、行列の特異値、検証用データの残差を求め、下表で判定する。

以下は本PoCの暫定受入基準であり、メーカー保証値や実測済み性能ではない。測定条件とともに試験前に固定し、不合格の結果に合わせて緩めない。

| 項目 | 合格条件 | 不合格・判定不能時 |
|---|---|---|
| 三つの干渉出力 | 全チャンネルで $A_i\geq5\sigma_i$、クリップなし | 配線・光パワー・偏波コントローラを確認。変調のない出力を復調へ投入しない |
| 位相の独立性 | $M$ のランクが2、特異値比 $s_{\max}/s_{\min}\leq10$ | 同相の強度モニタや劣化した干渉信号だけでは合格にしない |
| 再現性 | 別掃引で係数を固定し、各チャンネルの残差RMSが $0.1A_i$ 以下 | 校正のやり直し、光源変動・時間ずれ・ドリフトの切り分け |
| 位相範囲 | 一周期全体を覆い、往復掃引で同じ楕円を再現 | 短い円弧だけなら判定不能。三出力が正常とも異常とも断定しない |

残差は、固定した $\boldsymbol{b}$、$M$ と検証データから復元した位相による予測受光値との差とする。これは三チャンネルモデルの整合性を確認する検査であり、角速度の精度は11.4、11.5節で別途確認する。

基準設計で位相一周期に必要な角速度の変化幅は約222 rpmである。±30 rpmだけでは一周期の約27%しか覆えないため、−120～+120 rpmの掃引ができない場合は校正未完了として扱い、未校正の角速度でPoC完了としない。

### 11.3 ゼロ点

生の三チャンネル値の平均を位相オフセットとして差し引かない。11.2節の係数で $\phi_{\mathrm{raw}}$ を求め、短時間の静止データから円平均

$$
\phi_{\mathrm{bias}}=\mathrm{atan2}\left(\mathrm{mean}(\sin\phi_{\mathrm{raw}}),
\mathrm{mean}(\cos\phi_{\mathrm{raw}})\right)
$$

を求める。11.2節の位相原点では理想的な相反ポートに対して $\phi_{\mathrm{bias}}\approx0$ となるため、大きくずれる場合は偏波コントローラの状態とポート割当を確認する。静止時の標準偏差またはRMSも記録する。ここでのゼロは、設置姿勢、地球自転、機械台の残留回転を含む装置上の相対ゼロである。

### 11.4 スケールと符号

基準器で実際の角速度 $\Omega_n$ を測り、次の速度を各方向で複数回取得する。

```text
-30
-20
-10
0
+10
+20
+30 rpm
```

手動で「約」と測った値は動作確認用であり、スケール校正値には使わない。rpmを

$$
\Omega_n=\mathrm{rpm}\times\frac{2\pi}{60}
$$

で rad/s に変換し、11.3節の $\phi_{\mathrm{bias}}$ を差し引いてアンラップした $\Delta\phi_{\mathrm{S}}$ を

$$
\Delta\phi_{\mathrm{S}}=K_{\phi,\mathrm{meas}}\Omega_n+\delta_0
$$

として線形回帰する。傾き $K_{\phi,\mathrm{meas}}$ の単位は s である。切片 $\delta_0$ は残留ゼロ点としてゼロ点再現性とともに記録し、角速度換算には使わない。既知の正回転で $\Delta\phi_{\mathrm{S}}$ が正になることを確認する。

### 11.5 校正後の動作確認

11.1～11.4節の係数を固定し、それらの算出に使っていない別測定で確認する。

1. 基準器で +10 rpm を確認し、数秒間測定する。
2. 静止させ、ゼロ点の再現性を確認する。
3. 基準器で −10 rpm を確認し、位相の符号が反転することを確認する。
4. 10–30 rpmの複数速度を正負で測り、比例関係と残差を確認する。
5. 別の時刻または温度条件で同じ測定を繰り返し、ゼロ点ドリフトを記録する。

## 12. 主な誤差と簡易対策

理想式では時計回り／反時計回り光に共通する光路変化は相殺されるが、実機では温度分布、偏光、反射、部品不均衡、機械応力などが完全には相反にならず、回転と無関係な位相変化として現れる。簡易機ではこれらを完全に除去するより、**短時間測定・機械固定・チャンネル校正・ゼロ点校正**によって影響を抑える方針とする。

| 要因 | 症状 | 対策 |
|---|---|---|
| 温度変化 | ゼロ点ドリフト | コイルを断熱し、温度安定後に測定 |
| 偏光変動 | 干渉振幅の変化、ゼロ点の変化 | 偏波コントローラで可視度を最大化して固定し、ファイバへの曲げ・圧力を減らす |
| コネクタ反射・戻り光 | 不規則な干渉変動、光源への反射 | 端面清掃、未使用ポート終端、サーキュレータで光源を分離 |
| 3×3カプラ不均衡 | 位相計算の歪み | 個体の分岐比・位相を測定し、校正行列で補正 |
| 受光器・TIAゲイン差 | オフセット・楕円歪み | 暗オフセット、ゲイン、位相関係をチャンネルごとに校正 |
| 光源の出力変動・コヒーレント雑音 | 共通モード変動、干渉コントラスト低下 | 連続光・変調設定を固定し、必要なら光源を変更して比較 |
| TIA・ADCの飽和 | 波形クリップ、位相飛び | 光パワー、$R_f$、$C_f$、PGA、電源電圧を見直す |
| ADCの逐次変換・折り返し | チャンネル間の時間ずれ、エイリアシング | フレーム時刻を記録し、アナログ帯域を制限 |
| スリップリングの接触雑音 | 電源変動、通信エラー | 回転台上でレギュレータとデカップリングを通し、通信エラーのフレームを除外 |
| コイル形状・層数 | スケールファクタのずれ | 実効面積を見積もり、既知角速度で校正 |
| 軸の傾き | 角速度の投影誤差 | コイル面の法線と正回転方向を記録 |
| 機械振動・偏心 | 回転以外の信号 | コイルを剛性のある回転台へ固定し、保護カバーを付ける |

## 13. 安全上の注意

1550 nm 光は肉眼では見えない。

- 通電中のファイバ端面を覗かない
- 運転中の未使用ポートには光終端器を付け、停止中は防塵キャップを付ける
- 光源 ON のまま端面を清掃しない
- 製品のレーザークラスを確認する
- 必要以上に高出力の光源を使用しない
- TIA、ADC、光源の電源電圧と電流制限、スリップリングの定格を確認する
- 最高回転速度での遠心加速度（半径0.15 m・120 rpmで約2.4 g）に耐えるよう全部品とケーブルを固定し、偏心と保護カバーを確認する
- 光ファイバを切断した場合は、ガラス片を粘着テープ等で回収し、素手で触らない

## 14. まとめ

この3×3完成系PoCの核心は、**長尺ファイバを多巻きして有効面積を稼ぎ、同一コイルを逆方向に進む光の位相差を三つの戻り干渉出力から復元すること**にある。

- 3×3カプラ、3ポートサーキュレータ、ループ内偏波コントローラ、三つの受光チャンネルで光学系を構成する
- −120～+120 rpmの基準回転で三チャンネルのオフセットと校正行列を求め、位相バイアスとスケールファクタを校正する
- 正負の既知角速度で符号、残差、ゼロ点再現性を確認する
- 100 m / φ200 mm / 1550 nm：理論値 $K_{\phi,\mathrm{theory}}\approx0.2704\,\mathrm{s}$

精度を決める主因は理論式そのものより、温度、偏光、反射、機械応力、コイル形状、受光系の不均衡である。そのため、校正した係数を固定し、10–30 rpm程度の別測定で光学系と復調処理が正しく動作することを確認する。
